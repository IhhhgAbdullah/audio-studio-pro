# Audio Studio Pro

برنامج احترافي لتحرير الصوت وتحسينه على نظام Windows، يجمع التسجيل والتحرير والمؤثرات الصوتية في واجهة واحدة سهلة للمبتدئين والمحترفين.

## أهم الميزات
- تحرير الصوت: قص، دمج، حذف، تقسيم، نسخ ولصق، والتحكم بالسرعة والمستوى.
- مؤثرات صوتية: Echo، Reverb، Bass Boost، Equalizer، Pitch Shift، Chorus، Flanger وغيرها.
- تحسين الجودة: إزالة الضوضاء، تحسين وضوح الكلام، وضغط الصوت.
- تسجيل متعدد المسارات (Multitrack) مع دعم الميكروفونات الخارجية.
- صيغ مدعومة: MP3، WAV، FLAC، OGG، AIFF، M4A.
- واجهة عربية وإنجليزية مع الوضع الداكن والفاتح.
- يعمل دون اتصال بالإنترنت.
